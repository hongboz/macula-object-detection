# Macula & Optic Disc Detector

Detect anatomical structures in retinal fundus images using YOLO-NAS.

## Features
- Detects **macula** and **optic disc**
- Two model sizes: 640x640
- Adjustable confidence threshold

## Model
- Architecture: YOLO-NAS Medium
- Format: ONNX (optimized for deployment)
